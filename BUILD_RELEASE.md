# Release Build

## Что получится

После сборки будет создан файл:

`dist/WISH_Schedule/WISH_Schedule.exe`

Рядом с ним будут папки:

- `data/`
- `exports/`
- `imports/`
- `logs/`

Если в проекте уже есть база `data/schedule.db`, она будет автоматически скопирована в релизную папку при сборке.

## Сборка из git clone или из распакованного архива

Откройте PowerShell в корне проекта и выполните:

```powershell
./build_release.ps1
```

Скрипт автоматически:

1. создаст `.venv`
2. установит зависимости из `requirements.txt`
3. соберет `.exe` через `PyInstaller`
4. создаст рабочие папки в `dist/WISH_Schedule`
5. при наличии скопирует текущую БД в релиз

## Первый запуск

Запускать нужно:

```powershell
dist/WISH_Schedule/WISH_Schedule.exe
```

Приложение использует рабочую директорию рядом с `.exe`, поэтому корректно работает:

- из локального репозитория
- из распакованного zip-архива
- при переносе папки `dist/WISH_Schedule` на другой Windows-компьютер

## Иконка

Для `.exe` используется файл:

`Icon.ico`

## Если нужно пересобрать с нуля

```powershell
./build_release.ps1 -Clean
```
