## Автоматизированная система составления учебного расписания.

Desktop-приложение для составления учебного расписания на основе ограничений и оптимизации.

Проект предназначен для работы с семестровыми учебными планами, преподавателями, аудиториями, доступностью, черновиками и автоматической генерацией расписания. Генерация выполняется через `OR-Tools CP-SAT`, а локальное хранение данных реализовано на `SQLite`.

### Что умеет приложение

- вести несколько учебных календарей и семестров;
- хранить группы, преподавателей, дисциплины и аудитории;
- задавать доступность преподавателей по четной и нечетной неделе;
- закреплять преподавателей за конкретными группами;
- закреплять аудитории за конкретными дисциплинами;
- настраивать учебный план по дисциплинам, видам занятий и группам;
- поддерживать деление на подгруппы по отдельным видам занятий;
- создавать черновики расписания перед генерацией;
- запускать автоматическую генерацию расписания;
- сохранять варианты расписания и открывать их в редакторе;
- вручную дорабатывать сгенерированное расписание;
- работать с несколькими файлами баз данных `.db` и `.bd`.

### Основная идея

Приложение строит расписание как задачу удовлетворения ограничений.

При генерации учитываются:

- пересечения групп, преподавателей и аудиторий;
- типы занятий и типы аудиторий;
- вместимость аудиторий;
- доступность преподавателей;
- закрепления преподавателей за группами;
- закрепления аудиторий за дисциплинами;
- нагрузка по дням;
- окна и мягкие штрафы качества расписания;
- особенности четных и нечетных недель;
- черновики и зафиксированные назначения.

Если части данных не хватает, приложение умеет в ограниченном объеме продолжать генерацию с пустыми полями преподавателя или аудитории, чтобы пользователь мог позже доработать результат вручную.

### Для кого проект

Проект рассчитан на учебные подразделения, которым нужно:

- собрать единый учебный план по семестру;
- заранее проверить реализуемость расписания;
- быстро получить стартовый вариант;
- вручную доработать сложные случаи;
- хранить несколько независимых баз данных по разным наборам семестров.

### Интерфейс приложения

Основные вкладки:

- `Группы`
- `Аудитории`
- `Учебный план`
- `Преподаватели`
- `Черновики`
- `Генерация`
- `Расписание`

Дополнительно в верхней части главного окна:

- отображается текущая база данных;
- по клику можно переключиться на другую базу из папки `data`;
- доступно сохранение текущей базы данных целиком или по выбранным семестрам.

### Работа с базами данных

Приложение использует файлы `SQLite` из папки `data/`.

Если в папке `data/` находится несколько файлов БД, перед открытием главного окна приложение предлагает выбрать нужную базу.

После запуска текущую базу можно переключить прямо из главного окна по клику на поле `БД: ...`.

```text
app/
```

### Установка и запуск

#### 1. Создать виртуальное окружение и его активация

```bash
python -m venv .venv
```
Linux/macOS:

```bash
source .venv/bin/activate
```

Windows PowerShell/cmd:

```powershell
.venv\scripts\activate
```

#### 2. Установить зависимости

```bash
pip install -r requirements.txt
```

#### 3. Запустить приложение

```bash
python main.py
```

### Сборка Windows-версии

Для сборки используется `PyInstaller`.

См. подробности в файле `BUILD_RELEASE.md`.

Быстрый запуск сборки в PowerShell:

```powershell
./build_release.ps1
```

### Типовой сценарий работы

1. Создать или выбрать базу данных.
2. Добавить семестр.
3. Заполнить группы.
4. Заполнить аудитории и, при необходимости, закрепить их за дисциплинами.
5. Заполнить преподавателей, доступность и закрепления за группами.
6. Заполнить учебный план.
7. При необходимости создать черновик.
8. Запустить проверку реализуемости.
9. Запустить генерацию.
10. Открыть полученный вариант и при необходимости доработать вручную.

### Особенности текущей реализации

- приложение хранит данные локально и не требует серверной части;
- схема БД обновляется автоматически при открытии базы;
- генерация выполняется в отдельном процессе, чтобы не блокировать интерфейс;
- для сложных случаев можно использовать черновики и ручное редактирование;
- при нехватке части ресурсов генерация может оставить пустые поля в расписании для последующей ручной доработки.

### Ограничения

- качество результата зависит от полноты учебного плана и справочников;
- при сильном дефиците преподавателей или аудиторий генерация может быть остановлена проверками реализуемости;
- для корректной работы генератора обязательны установленные зависимости, в первую очередь `ortools`.

## Статус проекта

Проект представляет собой прикладной desktop-инструмент с активной доменной логикой вокруг учебного расписания. Основной фокус сделан на практической генерации, ручной корректировке результата и поддержке сложных учебных сценариев.
